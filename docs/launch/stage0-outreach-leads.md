Week-2 decision gate (issue #58) has real data.

## How to use this list

1. Fill in a named person (LinkedIn profile or public email) for each row before sending — do not
   DM a generic company inbox.
2. Send in batches of 5-10/day to avoid looking like spam and to allow time to personalize replies.
3. Use the pt-PT DM template in `announcement-templates.md` §3, personalized per-org.
4. Log every outcome in the Status column immediately — this feeds the Week-2 decision gate in
   issue #58 (≥1 pilot/paid/3 confirming conversations → proceed; 0 signal from 40-50 messages →
   pivot packaging or shut down the paid product deliberately).
5. Categories 1-2 are the primary buyer pool (operational budget for support tooling). Categories
   3-4 are more likely channel/reseller partners than direct buyers. Category 5 is
   credibility/amplification, not a sales target — treat replies there as qualitative signal only.
